# The Isle Server Hosting
A collection of info and files related to hosting a dedicated server on [The Isle](https://store.steampowered.com/app/376210/The_Isle/). This includes both Legacy and Evrima branches.

## To get started hosting your own dedicated The Isle server, refer to the [wiki](https://github.com/StolidSnow0/The-Isle-Server-Hosting/wiki).

Feel free to use the files from the repo to get your server setup.
